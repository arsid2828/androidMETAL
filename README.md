Per installare l'applicazione MetalMeteo seguire questi passaggi:
1. Assicuriamoci di avere una buona connessione internet e un dispositivo Android funzionante.
2. Scarichiamo il file APK MetalMeteo.apk nel nostro dispositivo Android.
3. Andare nei download e premere per scaricare il file usando l'installatore di pacchetti di Android. (Dare i permessi per acconsentire all'installazione)
4. Ad installazione completata, aprire l'app e assicurarsi di dare i permessi per posizione e notifiche.

In caso non si disponesse del file APK sarà possibile trovarlo a questo link https://github.com/arsid2828/androidMETAL/releases/tag/v1.1


Per creare l'apk dell'applicazione MetalMeteo seguire questi passaggi da Android Studio:
1. Aprire menu in alto a sinistra
2. Selezionare Build
3. Selezionare Generate App Bundles or APKs
4. Poi selezionare Generate APKs
5. Poi inviare l'apk al dispositivo Android e installare l'app
